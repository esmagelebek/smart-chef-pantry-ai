# Smart Chef & Pantry AI

Smart Chef & Pantry AI is a recipe recommendation application that helps users discover recipes based on the ingredients they have at home.

## Technology Stack

* Frontend: Flutter and Dart
* Backend: Python and Flask
* Database: PostgreSQL
* Database Hosting: Docker Desktop

## Project Structure

* `frontend/`: Flutter application
* `backend/`: Flask REST API
* `docs/`: Project documentation

## Development Status

Initial Flutter project created and successfully launched in Chrome.

## Planned Features

* Ingredient selection and search
* Recipe recommendations and matching percentages
* Missing ingredient identification
* Recipe details and external recipe links
* Favorites
* Shopping cart
* Social authentication
